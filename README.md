# 🏥 Hemodialysis Center Clinic Ali Allach Profile Website
## Overview
This project is a professional profile website for the Hemodialysis Center Clinic Ali Allach, built using React for the frontend and Express.js for the backend. The website is designed to provide comprehensive information about the clinic, offering a seamless user experience with responsive design, professional animations, and a built-in email server for direct communication with the clinic.

## Features
Clinic Profile: Detailed information about the clinic, its services, and the medical team.
Email Server: Integrated email functionality, allowing users to send messages directly to the clinic through the website.
Responsive Design: Fully optimized for all devices, ensuring a consistent and accessible experience.
Professional Animations: Smooth and visually appealing animations to enhance user engagement.
CSS Styling: Carefully crafted styles for a modern and clean look.
# Technologies Used
## Frontend:

React.js: For building a dynamic and interactive user interface.
CSS: For styling and ensuring a responsive and visually appealing design.
Animations: CSS and React libraries for professional-grade animations.
## Backend:

Express.js: For handling server-side logic and managing the email server.
Nodemailer: For sending emails directly from the website.
# Installation
To run this project locally, follow these steps:

## Clone the repository:
### `git clone https://github.com/mohamed-ako/centre_nephrologie.git`
## Navigate to the project directory:
### `cd centre_nephrologie`
# Install dependencies:

## For the backend:
### `cd centre_nephrologie`
### `cd express`
### `npm install`
## For the frontend:
### `cd centre_nephrologie`
### `npm install`
### Set up environment variables:

Create a .env file in the root of the backend directory and add the necessary environment variables for email configuration:
### EMAIL_SERVICE=your_email_service_provider
### EMAIL_USER=your_email_address
### EMAIL_PASS=your_email_password
# Run the application:

## Start the backend server:
### `cd centre_nephrologie`
### `cd express`
### `npm run server`

## Start the frontend development server:
### `cd centre_nephrologie`
### `npm start`
## Open the application:

### Visit http://localhost:3000 in your browser to view the site.
